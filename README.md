## 🌐 Como colocar na internet e gerar um Link no GitHub Pages (2 minutos)

Como você já tem uma conta no GitHub, você pode publicar este site gratuitamente e ter um link oficial (ex: `https://seu-usuario.github.io/dubai-campeoes/`):

### Passo a Passo Direto pelo Navegador (Sem precisar de terminal):
1. Acesse **[github.com](https://github.com)** e faça login.
2. Clique no botão verde **"New"** (ou no símbolo `+` no topo direito -> *New repository*).
3. Dê um nome para o repositório (exemplo: `dubai-campeoes` ou `viagem-dubai-2026`).
4. Deixe marcado como **Public** (Público) e clique em **"Create repository"**.
5. Na tela que abrir, clique no link **"uploading an existing file"** (carregar arquivos existentes).
6. Arraste todos os arquivos e pastas deste projeto para dentro da página do GitHub:
   - `index.html`
   - `README.md`
   - pasta `css/` (com `styles.css`)
   - pasta `js/` (com `data.js` e `app.js`)
7. Clique no botão verde **"Commit changes"**.
8. Agora, ative o GitHub Pages:
   - No topo do seu repositório, clique em **Settings** (Configurações).
   - No menu lateral esquerdo, clique em **Pages**.
   - Em **Branch**, selecione `main` (ou `master`) e a pasta `/(root)`.
   - Clique em **Save**.
9. Em cerca de 1 a 2 minutos, o GitHub vai gerar o link do site no topo dessa mesma página. Pronto! É só copiar o link e mandar no WhatsApp da organizadora!
